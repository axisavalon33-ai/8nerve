Connect the tablet and the VR phone

On the tablet / phone: open the Camera app (or Google Lens) and point it at the QR code, then tap the link. If Chrome says "Your connection is not private", tap Advanced → Proceed (it is your own laptop). The devices must be on the same Wi-Fi as this laptop.

QR codes not working? Try another address of this laptop
Still not connecting?
  • Check the tablet and phone are on the same Wi-Fi as the laptop (not a "guest" network – guest networks block devices from seeing each other).
  • Windows Firewall (most common cause): in the project folder, right-click allow-firewall-windows.cmd → Run as administrator. Or: Start → type Allow an app through Windows Firewall → Change settings → tick Node.js for Private (and Public) → OK. Also set the Wi-Fi to Private network (Settings → Network → Wi-Fi → your network → Private).
  • Using a phone hotspot? Some hotspots block devices from reaching each other – try a small pocket router instead.
  • After changing Wi-Fi, stop the server (Ctrl+C) and run npm start again – new QR codes appear.

Digit audio (hearing test)

Each language uses one complete set: your recordings when all 10 digits are recorded, otherwise the generated (computer voice) set. They are never mixed in one test. Uploaded MP3s are trimmed and evened out exactly like recordings.

Calibrate with normal listeners

The result bands depend on your digit recordings, headphones and room. Let 10–20 people with normal hearing (e.g. classmates who score well on a proper hearing test) do the test in each language, with the same tablet and headphones. Their results are not counted as visitors. The suggestion is: GOOD up to their average + 2 × SD, REFER above that + 3 dB.

⚠ Calibration mode is ON – remember to switch it OFF before visitors arrive.

You can also tick Normal listener next to any result in the table below.
